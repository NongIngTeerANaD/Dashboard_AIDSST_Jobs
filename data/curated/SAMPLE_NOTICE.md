# หมายเหตุ: ข้อมูลตัวอย่าง (SAMPLE_DEMO)

แถวที่มี `source_id = SAMPLE_DEMO` ใน programs / graduates / courses / tuition / skills_demand เป็น **ข้อมูลตัวอย่างสำหรับสาธิตการทำงานของ Dashboard เท่านั้น**
ไม่ได้มาจากแหล่งข้อมูลจริง (จำนวนผู้จบ ค่าเทอม รายวิชา และคะแนนความต้องการ skill เป็นตัวเลขสมมติ) ห้ามนำไปอ้างอิงหรือเผยแพร่เป็นข้อเท็จจริง

วิธีแทนด้วยข้อมูลจริง: แก้ไขไฟล์ใน data/curated/ โดยใส่ข้อมูลจากเอกสารหลักสูตร/ประกาศค่าเล่าเรียนของสถาบัน พร้อม source_url จริง และเปลี่ยน source_id เป็น CURATED_USER
สำหรับ skills_demand: ให้รัน `python -m etl.fetch_s03_onet` แล้วสร้างคะแนนจาก O*NET (ต้องมีเครือข่ายที่เข้าถึง onetcenter.org)
